# Ember to Empire — своя онлайн-версия (без claude.ai)

В папке: `index.html` (игра), `server.js` (сервер без зависимостей, нужен только Node 18+), `Dockerfile`.

## Запуск у себя
    node server.js            # порт 8080, или PORT=3000 node server.js
Откройте http://localhost:8080/ — это игра. «Онлайн» → «Создать комнату», друзья входят по коду.

## Друзья в той же сети (Wi-Fi/LAN)
Дайте им адрес http://<ваш-IP>:8080/ (IP: `ipconfig` / `ip a`). Откройте порт 8080 в брандмауэре.

## Друзья через интернет
- Быстро и бесплатно: `cloudflared tunnel --url http://localhost:8080` (или `ngrok http 8080`) — выдаст https-ссылку, отправьте её друзьям.
- Постоянно: любой хостинг с Node или Docker (Render, Railway, Fly.io, VPS). Команда запуска: `node server.js`. Для сохранения комнат подключите диск и укажите `DATA_FILE=/data/data.json`.

## Что внутри
Сервер хранит документы комнат (журнал команд, часы, мета) и рассылает изменения по SSE (один поток на игрока). Игра делает то же, что и в claude.ai, но вместо базы claude использует этот сервер. Хозяин комнаты по-прежнему ведёт время (его вкладка должна быть открыта).

## Для Steam
`steam/main.js` может открывать ваш сервер: `WA_SERVER_URL=https://ваш-сервер npm start`.
Ограничения: нет входа и защиты (любой, кто знает адрес и код комнаты, может войти), нет анти-чита, данные в одном JSON-файле — это подходит для игры с друзьями, но не для публичного релиза.
